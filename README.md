# Crocs by Dya – E-commerce Website

Online store connected to a MySQL database. University project completed as a pair.

## Features
- Product management: suppliers, prices, colors and models
- Order management: customers and dates

## Technologies
HTML, CSS, JavaScript, PHP, SQL (MySQL, phpMyAdmin)

## My Contribution
- Designed the database with ER (Entity-Relationship) models
- Created the tables and wrote the SQL queries
- Developed the website (PHP, JavaScript)
- AI was used only for CSS styling
